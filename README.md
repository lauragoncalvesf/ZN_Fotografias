# ZN Fotografias — Landing page v2

Abra `index.html` no navegador ou use Live Server no VS Code. Não é necessário instalar dependências.

## Personalização

- Substitua os blocos `.photo-art` da primeira tela pelas fotos autorizadas do estúdio, eventos, esportes, casamentos e conteúdo.
- Substitua os blocos `.gallery-image` por imagens reais do portfólio; os filtros já funcionam.
- Preencha os cartões da seção **Equipe** com fotos, nomes e funções confirmados. José Erick está identificado como fotógrafo; os outros cartões são placeholders.
- Confirme o WhatsApp antes de alterar o link de orçamento, atualmente direcionado ao Instagram oficial.
- A animação acompanha a rolagem no desktop; em telas pequenas e com preferência por movimento reduzido, o layout permanece simplificado.

## Arquivos

`index.html` estrutura; `style.css` identidade e responsividade; `script.js` filtros e animação; `assets/logo-zn.jpeg` logo fornecida; `SKILL.md` diretrizes do projeto.
